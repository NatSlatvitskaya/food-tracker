# 🥗 Трекер питания

Мобильный веб-трекер питания и прогресса в стиле Apple (iOS). Первая версия — чистый HTML + CSS + минимум JS, без сборки и зависимостей.

## Экраны

| Экран | Описание |
|---|---|
| **Онбординг** | Ввод параметров тела (вес, талия, бедра, ягодицы, возраст, целевой вес) и расчёт цели через ИИ-агента |
| **Главная** | Приветствие, кольцо прогресса калорий, полоски БЖУ, добавление приёма пищи |
| **История** | Лента приёмов пищи за день с КБЖУ |
| **Прогресс** | Текущие замеры с датой обновления, внесение новых, место под график |

## Стек

- HTML5 (семантичная разметка)
- CSS3 (переменные, `backdrop-filter`, SVG-градиенты)
- Vanilla JS (переключение вкладок, шторки, `localStorage`)

## Локальный запуск

Просто открой `index.html` в браузере — сборка не требуется.

Для корректной работы через `http://` (например, для доступа с телефона по локальной сети):

```bash
python3 -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Публикация на GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `main`, папка `/ (root)`
4. Save → сайт будет доступен по адресу `https://<username>.github.io/<repo>/`

Файл `index.html` должен лежать в корне репозитория.
