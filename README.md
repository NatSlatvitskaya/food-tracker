# 🥗 Трекер питания

Мобильный веб-трекер питания и прогресса в стиле iOS. Рассчитывает КБЖУ через ИИ (OpenRouter + Gemini Flash), распознаёт блюда по фото с камеры телефона.

## Экраны

| Экран | Описание |
|---|---|
| **Онбординг** | Ввод параметров тела и цели веса → ИИ считает норму калорий по Миффлину-Сан Жеору |
| **Главная** | Кольцо калорий, полоски БЖУ, добавление приёма пищи по фото |
| **История** | Лента приёмов пищи за день с распознанным КБЖУ |
| **Прогресс** | Замеры с датой обновления, внесение новых, место под график |

## Стек

- HTML5, CSS3 (переменные, `backdrop-filter`, SVG-градиенты)
- Vanilla JS, без сборки и зависимостей
- `localStorage` — все данные пользователя
- OpenRouter API, модель `google/gemini-flash-1.5`

## Ключ API

**Ключ не хранится в коде.** `app.js` на GitHub Pages публичен — любой может открыть его и прочитать. Поэтому ключ вводится один раз прямо в приложении и сохраняется в `localStorage` браузера под именем `tracker.apiKey`.

При первом обращении к ИИ появляется окно ввода ключа. Получить ключ: [openrouter.ai/keys](https://openrouter.ai/keys).

Заменить или удалить ключ можно из консоли браузера:

```js
localStorage.removeItem('tracker.apiKey'); // при следующем запросе спросит заново
```

## Обновление и кэш

В `index.html` ссылки на файлы содержат параметр версии:

```html
<link rel="stylesheet" href="style.css?v=3">
<script src="app.js?v=3"></script>
```

**При каждом обновлении `style.css` или `app.js` увеличивайте число в `?v=`.** Иначе Chrome на Android может отдавать старые файлы из кэша, и изменения «не применяются».

Проверить, какой файл реально загружен, можно, открыв в браузере `https://<username>.github.io/<repo>/app.js` и поискав в тексте свежие строки.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Затем `http://localhost:8000`.

## Публикация на GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `main`, папка `/ (root)`
4. Save → сайт доступен по адресу `https://<username>.github.io/<repo>/`

## Ограничения текущей версии

- История показывает только сегодняшний день, переключателя дат нет
- График прогресса — пустой контейнер, визуализации ещё нет
- Бесплатные модели OpenRouter имеют лимит запросов: при 429 приложение просит подождать минуту
- Фото хранятся в `localStorage` миниатюрами по ~50 КБ; при переполнении квоты фото у последней записи удаляется, КБЖУ остаётся
