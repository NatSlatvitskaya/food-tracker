# 🥗 Трекер питания

Мобильный веб-трекер питания в стиле iOS. ИИ считает КБЖУ по составу блюда и фото (OpenRouter + Gemini).

## Экраны

| Экран | Что делает |
|---|---|
| **Онбординг** | Параметры тела и цель веса → ИИ считает норму калорий по Миффлину-Сан Жеору |
| **Главная** | Кольцо калорий, полоски БЖУ, добавление приёма пищи, кнопка настроек |
| **История** | Карточки за день с КБЖУ и раскрывающимся составом |
| **Прогресс** | Замеры с датой обновления |

## Добавление блюда

Блюдо вводится **по ингредиентам**: каждый продукт с отдельным весом. ИИ получает список вроде «куриная голень — 180 г, пюре — 200 г» и считает точнее, чем по одному общему весу. Фото необязательно, но с ним точность выше.

Состав сохраняется вместе с приёмом пищи и показывается в истории под ссылкой «Состав».

## Настройки и сброс данных

Кнопка с шестерёнкой в шапке Главной:

- **Ключ OpenRouter** — маскированный показ, кнопка «Заменить»
- **Сбросить все данные** — профиль, приёмы пищи, замеры. Ключ остаётся. Требует двух нажатий
- **Сбросить всё и удалить ключ** — то же плюс удаление ключа API

Сброс возвращает приложение на онбординг, как при первом запуске.

## Ключ API

Ключ не хранится в коде: `app.js` на GitHub Pages публичен. Он вводится один раз и лежит в `localStorage` под именем `tracker.apiKey`.

Получить ключ: [openrouter.ai/keys](https://openrouter.ai/keys).

Удалить ключ из консоли: `localStorage.removeItem('tracker.apiKey')`.

## Модели

Проверяются по порядку, при 404 или 5xx берётся следующая:

1. `google/gemini-2.5-flash`
2. `google/gemini-2.5-flash-lite`
3. `google/gemma-4-31b-it:free`

Список в `API_MODELS` в начале `app.js`. Актуальные модели: [openrouter.ai/models](https://openrouter.ai/models).

## Кэш

В `index.html` ссылки версионированы:

```html
<link rel="stylesheet" href="style.css?v=5">
<script src="app.js?v=5"></script>
```

**При каждом обновлении этих файлов поднимайте число.** Иначе Chrome на Android отдаст старые версии из кэша.

## Локальный запуск

```bash
python3 -m http.server 8000
```

## Публикация

Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

## Ограничения

- История показывает только сегодня, переключателя дат нет
- График прогресса — пустой контейнер
- Бесплатные модели имеют лимит запросов (429)
- Фото в `localStorage` миниатюрами ~50 КБ, при переполнении удаляются
